# The Reading Room 📚

The Reading Room is a responsive online bookstore built with React, Vite, and Tailwind CSS.

The project provides a clean and user-friendly interface for browsing books, filtering them by category, and selecting quantities.

## Features

- Responsive, mobile-first design
- Book catalog organized into reusable components
- Category filtering with React state
- Reusable quantity stepper for each book
- Modern styling with Tailwind CSS
- Accessible interactive controls

## Technologies

- React
- Vite
- Tailwind CSS
- JavaScript
- ESLint
